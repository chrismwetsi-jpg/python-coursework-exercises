# Python Coursework Exercises
This repository contains my Python coursework for Introduction to Python.

- `01_Full_Python_Basics.ipynb` - All basics: variables, data types, loops, functions, error handling, OOP, file handling

1. Clone repo
2. Open in Jupyter Notebook / Anaconda
3. Run all cells
